# Avo! Remaster APK

The compiled Android application package (APK) is located in this directory:

- **File**: `avo-remaster.apk`
- **Build Type**: Debug (`assembleDebug`)
- **Fidelity**: Includes the original 1080x1920 25 fps video plates, original 3D polygonal models & textures rendered to sprites, original Wwise audio foley/music, and touch-path mechanics.

### How to Install on Android
1. Download `avo-remaster.apk` to your Android device.
2. Enable "Install from unknown sources" in your Android system settings if prompted.
3. Open `avo-remaster.apk` to install and launch **Avo Remaster**.
